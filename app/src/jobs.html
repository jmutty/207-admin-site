Search settings

Categories hold the default search fields and labels. Each GotPhoto job type belongs to one category and inherits from it. The switch on a type makes its jobs findable on the website. A single job can still override anything from its own drawer on the Jobs tab.

Blocked names

Children whose name must never unlock a code on Find My Photos — for parents who ask that their child not be findable by name. Nothing is deleted: the family's own code from the card keeps working, and the parent simply sees “not found”. A block covers every job, past and future, unless you pick one job. Help requests and the alert emails for a blocked name are flagged so nobody sends the code back by email. Matching is by exact name as spelled in GotPhoto — the On roster column tells you whether the block is actually hitting anyone.
